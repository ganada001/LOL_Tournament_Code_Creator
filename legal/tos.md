# 이용약관

최종 수정일: 2026년 6월 23일

## 1. 서비스 목적

LOL Tournament Code Creator는 League of Legends 커뮤니티 대회 운영을 돕기
위해 Riot Tournament API 기반 토너먼트 코드 발급 흐름을 제공하는 운영
도구입니다.

## 2. 사용자의 의무

- 사용자는 Riot Games 개발자 정책과 관련 대회 운영 정책을 준수해야 합니다.
- 본 도구를 불법적인 목적, 타인의 게임 이용 방해, 도박 또는 부정행위 목적으로
  사용해서는 안 됩니다.
- 운영자는 본인이 관리 권한을 가진 Discord 웹훅과 대회 설정만 등록해야 합니다.
- 본 도구는 사용자에게 Riot API 키를 요구하지 않으며, 모든 Riot API 호출은
  인증된 보안 백엔드를 통해 처리됩니다.

## 3. 비영리 커뮤니티 운영

본 도구는 커뮤니티 대회 운영 편의를 목적으로 합니다. 상금, 참가비, 후원 등
금전 요소가 있는 대회를 운영하는 경우 Riot의 토너먼트 및 수익화 정책을 별도로
확인해야 합니다.

## 4. 책임의 한계

- 본 도구는 있는 그대로 제공되며, Riot API 정책 변경, 서비스 장애, API 제한으로
  인해 기능이 제한될 수 있습니다.
- 운영자의 잘못된 대회 설정, 웹훅 관리, 정책 위반으로 발생하는 문제는 운영자에게
  책임이 있습니다.

## 5. 약관 변경

본 약관은 필요한 경우 변경될 수 있으며, 최신 내용은 GitHub 저장소와 공개
페이지를 통해 확인할 수 있습니다.
